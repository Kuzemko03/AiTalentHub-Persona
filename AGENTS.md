# Работа с AiTalentHub-Persona

Собственная база Джокера, трек 2 AI Persona Lab. Цель текущего этапа:
рабочее место, текстовый диалог, маски, память, Telegram и локальная панель.
Статус и границы задания находятся в docs/lesson-3.md.

- Python 3.11+, стандартная библиотека; зависимости добавлять по реальной нужде.
- Основа личности и маски — в agent/joker, runtime — в joker/.
- Смена маски сохраняет память; стоп отменяет старую генерацию и очередь.
- Токены, личные диалоги и база остаются в игнорируемых локальных файлах.
- Проверка: python -m unittest discover -s tests -v; python tools/check.py.
- Перед публикацией: python tools/check_public.py и просмотр git diff --cached.
- Мок адаптера проверяет код; качество персонажа подтверждает только живой запуск.
- agent/AGENTS.md описывает поведение персонажа, а не кодингового ассистента.
