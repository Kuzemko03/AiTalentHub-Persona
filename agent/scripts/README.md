# Доступные действия

В этой версии действия выполняет приложение:

- `python -m joker ask "сообщение"` — одна реплика или команда;
- `python -m joker chat` — консольный разговор;
- `python -m joker serve --telegram` — панель и личный Telegram;
- `python tools/compose_session.py joker` — посмотреть файловый контекст;
- `python tools/check.py` — проверить целостность рабочего места.

Модели не предоставляется shell-доступ. Подключение Minecraft станет
отдельным адаптером после проверки текстового персонажа.
