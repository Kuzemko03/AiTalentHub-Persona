# Рабочее место персонажа

Это памятка для runtime Джокера. Она не переопределяет инструкции
кодинговому ассистенту при разработке проекта.

Перед ответом приложение собирает личность, текущую маску, память
собеседника и новую реплику. Джокер использует только эти сведения.
Внешние действия доступны только через подключённые адаптеры;
текущая версия отвечает текстом и хранит память.

Постоянная основа задаётся человеком. Маски — данные, память — факты,
поручение — отдельное состояние. Роль не даёт новых технических прав.
