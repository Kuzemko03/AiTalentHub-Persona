# Формат памяти

Основа личности хранится в PERSONA.md. Краткое оперативное состояние,
факты и связанные заметки сохраняются в приватной SQLite-базе data/joker.sqlite3.
Память выбирается под текущую реплику, а не загружается целиком.

Заметки бывают о людях, местах, договорённостях, событиях и свободной формы.
До 500 на область, связи только внутри области. Для контекста выбираются
до 24 фактов и 5 заметок с ограничением размера; поиск фактов охватывает
последние 2048 записей. История — 12 последних реплик одного собеседника.
Каталог entities сохранён для совместимости, записная книжка работает через SQLite.
Ни база, ни личные заметки не публикуются. Смена маски не очищает память.
Вымышленная биография роли не становится памятью о реальном человеке.

Личная область owner не поступает в ответы Minecraft/созвона. Игровые
собеседники имеют раздельные записи; дополнительно им доступны только
явно подготовленные владельцем общие заметки world:minecraft.
Созвон использует call:shared. Подробнее — docs/memory.md в корне проекта.
