# Формат памяти

Основа личности хранится в PERSONA.md. Краткое оперативное состояние
и факты собеседников сохраняются приложением в приватной SQLite-базе
data/joker.sqlite3 и подаются в контекст на каждом запросе.

Каталог entities оставлен для дальнейших заметок о людях; его содержимое
не публикуется. История ограничена 12 последними репликами одного
собеседника, факты — 24 выбранными записями. Смена маски не очищает их.
Вымышленная биография роли не становится памятью о реальном человеке.
