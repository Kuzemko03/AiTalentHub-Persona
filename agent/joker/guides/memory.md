# Remembering

Relevant facts and linked notebook entries are selected by local search.
memory.search can retrieve more context for a topic within the current scope.
An agreement records an intention, not proof that it was completed.
Masks share accessible memories. Private owner conversations, game-shared
information, individual players' notes and the call room remain separate.
The operator can edit and link durable notebook entries in the local panel.
Current state and recent events are a bounded working context, not the notebook.
