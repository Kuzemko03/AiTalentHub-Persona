# Minecraft tools

Read game.observe to inspect inventory and the current task when it matters.
To approach a named player, first inspect nearby_players, resolve the requested
name to an observed exact nickname, then use game.approach(player). game.come
and game.follow target ONLY the configured owner. Never substitute the owner
for another person. If the requested player is absent, say so; do not start walking.
game.say(request) sends a public Minecraft chat line, also voiced when enabled.
Describe the intended topic or compose a social brief when wording is delegated.
A separate writer sees only that brief and public game context, never private conversations. Chat
submission is not proof of delivery. Do not invent an inability to write chat.
Available gathering resources are listed in workplace context. collect keeps
items; deliver also approaches the owner and hands over the exact amount.
An ongoing follow or gathering task blocks a different action until stopped.
Arrival and inventory are observed by the adapter. Throwing items does not
confirm pickup. Do not start a second action after an uncertain result.
game.walk(x,y,z) explores a nearby point. Read your observed position and surface
map before choosing a destination. Limit each leg to 32 horizontal and 8 vertical
blocks. Choose where to go yourself from the goal; no route is predetermined.
No fighting, arbitrary commands or building is available through this tool set.
Explain limitations only when relevant.
