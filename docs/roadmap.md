# Джокер: реализация по плану

Обновлено 21 октября 2026. Трек 2, собственная база. Владелец попросил сначала
реализовать следующие части, затем совместно проверять их в игре и голосе.
Поэтому здесь отдельно отмечены наличие кода и проверка настоящей среды.

| Этап | Реализация | Проверка настоящей среды |
|---|---|---|
| Рабочее место, репозиторий | Личность, маски, SQLite, публичный GitHub | Подтверждено ранее |
| Текст, Telegram, панель | GPT-6 Luna, собственные роли, общая история, отмена ответа | Подтверждено ранее; см. lesson-3.md |
| Долговременная память · 0.4.0 | Люди/места/договорённости, связи заметок, поиск, важные записи, отдельные области, редактор и JSON-выгрузка | Автоматические проверки; поведение в живом диалоге отложено |
| Рабочее место · 0.5.0 | Модель выбирает инструменты и роль в обычном разговоре, читает руководства по индексу и получает результат | Автоматические проверки исполнителя; живое понимание формулировок отложено |
| Опыт и состояние · 0.5.0 | События игры, журнал инструментов и сбоев, настроение/занятие/фокус, локальный JSON-отчёт | Автоматические проверки; реальные callbacks и поведение в игре отложены |
| Поручения по шагам · 0.6.0 | До 8 сохранённых шагов, решения модели по наблюдениям, управление в панели, ручная проверка неоднозначного результата | Автоматические проверки; совместная проверка с игровым клиентом отложена |

| Голос в игре | PCM UnionClef → STT → тот же персонаж → TTS → выбранный выход | Нужны сервисы STT/TTS и аудиокабель; отложена |
| Созвоны | Отдельный аудиовход и выход, ответы на имя, отдельная память комнаты | Нужна настройка двух аудиокабелей; отложена |
| Публичный игровой сервер | Настраиваемый адрес и отдельное разрешение подключения, повтор не чаще раза в минуту | Нужны выбранный сервер, ники и запущенный клиент; отложена |
| Самостоятельная работа | Цель, решения модели из ограниченного списка инструментов, журнал, бюджет | Код и автоматические проверки; поведение в игре отложено |
| Сон и бодрствование | Команды, расписание через полночь, сохранение цели/плана, остановка действий | Автоматические проверки; длительная работа отложена |
| Автозапуск и восстановление | Windows-задача, supervisor, один экземпляр, SQLite-копии | Автозапуск не устанавливался; проверка входа в Windows отложена |

Это реализация учебного объёма, не универсальный агент, умеющий любое действие.
Доступные игровые действия перечислены в [minecraft.md](minecraft.md).
Автономный цикл выбирает только из них, не запускает shell и не публикует посты.
Для новой возможности нужен отдельный инструмент и проверка результата.

## Как продолжить позже

1. Заполнить игровые ники и открыть профиль Minecraft с UnionClef.
2. Проверить чат, подход, следование, маску, стоп и сбор ресурсов.
3. Проверить передачу ровно 16 предметов из стака 64, открытое меню,
   уход владельца, потерю соединения и отсутствие повторной передачи.
4. Настроить сервисы и устройства из [voice.md](voice.md), проверить голос один
   на один, потом несколько участников по очереди. Снять задержки этапов.
5. В отдельном тестовом мире задать небольшую цель, включить автономность,
   проверить остановку, бюджет и восстановление плана после перезапуска.
6. Проверить сон через полночь, ручное пробуждение и включить автозапуск
   по [operations.md](operations.md). Провести продолжительную сессию.
7. Пройти сценарий [связанной памяти](memory.md): напарник → экспедиция,
   смена маски, поиск старого воспоминания, проверка областей доступа.

## Следующие блоки после записной книжки

Журнал, модельные инструменты обычного разговора и короткое изменяющееся
состояние реализованы в [рабочем месте 0.5](workplace.md). Обычные намерения
не выбираются по фразам или ключевым словам; явные команды и проверки
исполнителя остаются в коде.

Очередь нескольких поручений с проверкой каждого шага реализована в
[версии 0.6](errands.md). Дальше: отдельные профили игровых миров, серверов
и координат; ведение долговременных связанных заметок самим персонажем.
Это следующие идеи, а не готовые возможности.
Основания и временные метки лекции — в [разборе занятия 3](lecture-3-review.md).
Живые проверки общего сценария с текстом, действиями и памятью остаются
отложенными по просьбе владельца.

## Что изменилось в материалах курса

Конспект [занятия 3](https://course.personalabs.ru/lessons/3/materials)
уже опубликован 17 октября. Его основной цикл отражён в реализации:
событие → контекст → решение → ограниченный инструмент → наблюдение → план.
С версии 0.5 модель выбирает игровые инструменты также в обычном разговоре;
он и автономный режим используют одного исполнителя и общую игровую область опыта.
`docs/lesson-3.md` оставлен исторической записью проверки от 15 октября;
указание в нём о неопубликованных материалах относится к той дате.

Текущий путь проекта: папка `AiTalentHub-Persona` в каталоге персонажа.
Личные данные, аудио и копии не входят в Git. Коммиты и CI подтверждают
воспроизводимость кода, но не успех действий в игровом мире.
