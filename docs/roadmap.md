# Джокер: реализация по плану

Обновлено 21 октября 2026. Трек 2, собственная база. Владелец попросил сначала
реализовать следующие части, затем совместно проверять их в игре и голосе.
Поэтому здесь отдельно отмечены наличие кода и проверка настоящей среды.

| Этап | Реализация | Проверка настоящей среды |
|---|---|---|
| Рабочее место, репозиторий | Личность, маски, SQLite, публичный GitHub | Подтверждено ранее |
| Текст, Telegram, панель | GPT-6 Luna, собственные роли, общая история, отмена ответа | Подтверждено ранее; см. lesson-3.md |
| Minecraft | UnionClef, обращения по имени, следование, подход, добыча, точная передача и стоп | Отложена |
| Голос в игре | PCM UnionClef → STT → тот же персонаж → TTS → выбранный выход | Нужны сервисы STT/TTS и аудиокабель; отложена |
| Созвоны | Отдельный аудиовход и выход, ответы на имя, отдельная память комнаты | Нужна настройка двух аудиокабелей; отложена |
| Публичный игровой сервер | Настраиваемый адрес и отдельное разрешение подключения, повтор не чаще раза в минуту | Нужны выбранный сервер, ники и запущенный клиент; отложена |
| Самостоятельная работа | Цель, решения модели из ограниченного списка инструментов, журнал, бюджет | Код и автоматические проверки; поведение в игре отложено |
| Сон и бодрствование | Команды, расписание через полночь, сохранение цели/плана, остановка действий | Автоматические проверки; длительная работа отложена |
| Автозапуск и восстановление | Windows-задача, supervisor, один экземпляр, SQLite-копии | Автозапуск не устанавливался; проверка входа в Windows отложена |

Это реализация учебного объёма, не универсальный агент, умеющий любое действие.
Доступные игровые действия перечислены в [minecraft.md](minecraft.md).
Автономный цикл выбирает только из них, не запускает shell и не публикует посты.
Для новой возможности нужен отдельный инструмент и проверка результата.

## Как продолжить позже

1. Заполнить игровые ники и открыть профиль Minecraft с UnionClef.
2. Проверить чат, подход, следование, маску, стоп и сбор ресурсов.
3. Проверить передачу ровно 16 предметов из стака 64, открытое меню,
   уход владельца, потерю соединения и отсутствие повторной передачи.
4. Настроить сервисы и устройства из [voice.md](voice.md), проверить голос один
   на один, потом несколько участников по очереди. Снять задержки этапов.
5. В отдельном тестовом мире задать небольшую цель, включить автономность,
   проверить остановку, бюджет и восстановление плана после перезапуска.
6. Проверить сон через полночь, ручное пробуждение и включить автозапуск
   по [operations.md](operations.md). Провести продолжительную сессию.
