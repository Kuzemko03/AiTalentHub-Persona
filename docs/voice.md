# Голос в Minecraft и созвонах

Голосовой тракт реализован, но настоящая аудиосессия отложена по просьбе
владельца. По умолчанию он выключен. Установка зависимости ничего не записывает.

В версии 0.7 добавлены [локальный Piper и режим одной озвучки](tts-local.md).
В версии 0.8 — [выбор устройств в панели и проверка готовности](setup.md).
Сохранённый в панели маршрут имеет приоритет над устройствами из `.env`.
Два русских тембра проверены настоящим синтезом WAV; игровая аудиосессия
по-прежнему отложена. В панели можно закрепить голос за ролью и создать пример
без микрофона, аудиоустройства и STT. Ниже описан полный разговорный HTTP-тракт.

## Настройка сервисов

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[minecraft,voice]"
.\.venv\Scripts\python.exe -X utf8 -m joker audio-devices
```

Настройки в локальном `.env`:

```dotenv
VOICE_ENABLED=0
VOICE_GUESTS=0
VOICE_MODE=conversation
STT_URL=
STT_MODEL=
STT_API_KEY=
TTS_URL=
TTS_MODEL=
TTS_API_KEY=
TTS_VOICE=
TTS_BACKEND=http
TTS_DAILY_CHARACTERS=20000
VOICE_OUTPUT_DEVICE=
VOICE_INPUT_DEVICE=
```

Нужны полные адреса двух совместимых HTTP API. Поставщик не выбран за владельца:
это могут быть локальные сервисы или внешний провайдер. Текущий вход в ChatGPT
для текстовой модели сам по себе не настраивает аудиосервисы. Ключи задаются
отдельно; они не передаются текстовой модели. Перед включением внешнего сервиса
следует учитывать его тариф: звук/текст уходят по настроенному адресу.

Контракт распознавания: POST multipart с полями `model` и `file=speech.wav`,
ответ JSON `{"text":"распознанная речь"}`. На входе WAV mono PCM16LE, 48 кГц.
Контракт синтеза: POST JSON с `model`, `voice`, `input`, `response_format="wav"`;
ответ — бинарный WAV PCM16, mono/stereo, 8–48 кГц, не более 60 секунд.
`Authorization: Bearer ...` добавляется только при непустом ключе.
Разрешены HTTPS и локальный HTTP. Перенаправления и автоматические повторы
запросов отключены. Иной формат провайдера требует адаптации этих двух методов.

`VOICE_OUTPUT_DEVICE` — конкретное имя или индекс выхода из списка устройств.
Автоматический выбор обычных динамиков не используется. При индексе список
может поменяться после подключения устройства; имя обычно удобнее.

## В Minecraft

Вход — `onVoiceFeed` UnionClef: звук отдельных игроков с их никами.
`VOICE_GUESTS=0` принимает только речь игрового владельца. Значение 1 разрешает
гостей, но не даёт им права менять роль или задавать действия. Проверка ником
подходит для доверенного сервера; это не отдельная авторизация.

Для выхода выберите виртуальный кабель в `VOICE_OUTPUT_DEVICE`, а его вторую
сторону — микрофоном в Simple Voice Chat игрового клиента Джокера.
В моде должны быть включены микрофон и голосовая активация. Порядок настройки
мода описан в [инструкции курса](https://course.personalabs.ru/instructions/minecraft).

```powershell
.\.venv\Scripts\python.exe -X utf8 -m joker serve --minecraft --voice
# или из уже открытой панели: «Включить голос»
```

Текст ответа также остаётся в игровом чате. Обращение — по имени Джокера,
игровому нику или имени маски. Голосовой текст проходит те же проверки прав
и ограниченные команды, что игровой чат. Ошибки распознавания могут изменить
поручение: сначала проверяйте это в тестовом мире.

## В созвоне

`VOICE_INPUT_DEVICE` по умолчанию пуст: захвата системного звука нет.
При явно выбранном входе сервис открывает только его, 48 кГц mono PCM16.
Направьте звук других участников созвона в отдельный виртуальный кабель,
вторую сторону укажите здесь. Выход Джокера идёт через другой кабель в микрофон
программы созвона. Один кабель для обоих направлений создаёт петлю звука.
Подключение к самому звонку выполняется в программе звонка; бот не вступает
в чужие звонки автоматически и не управляет аккаунтом Discord/Telegram.

По общему звуку нельзя надёжно определить человека. Поэтому такой вход
использует общую память `call:shared`, отделённую от личного Telegram и игры.
Он вызывает только разговорный ответ, никогда команды управления или публикации.
Включённый голос с двумя настроенными кабелями работает без Minecraft.

## Маски, остановка и пределы

`/голос тембр ID` запоминает ID тембра текущей маски из вашего TTS-сервиса.
Без отдельной настройки используется `TTS_VOICE`. Новая маска сама по себе
не создаёт новый синтетический голос. `/голос выкл` закрывает аудиовход и очереди.
При включённом голосе озвучиваются ответы и на текстовые обращения в Minecraft.
Смена маски, сон и «Стоп» отменяют старое аудио, включая ещё готовящийся синтез.

Распознавание отделяет фразу по паузе 650 мс. Минимум 300 мс речи, максимум
10 секунд; слишком длинная фраза отбрасывается целиком. Порог громкости простой,
поэтому шумный микрофон и длинные паузы внутри фразы потребуют живой настройки.
Четыре буфера говорящих и очереди по четыре элемента ограничивают нагрузку.
Распознавание — не чаще одного запроса в 3 секунды, максимум 100 в сутки UTC.
Лимит текстовой модели действует дополнительно. Сырые записи не сохраняются.

Во время воспроизведения новый звук не принимается: это полудуплексный режим
для защиты от эха. Поэтому голосом перебить Джокера во время его речи пока
нельзя; используйте кнопку «Стоп» или текст. Доступные метрики в панели:
распознавание, подготовка ответа и время от готового текста до начала вывода.
Последняя метрика не подтверждает, что звук дошёл до другого участника.

## Проверка позже

Проверить фактическое распознавание русского, адресацию, гостей, шум и паузы;
сравнить тембры масок; переключить роль во время синтеза; остановить длинную
реплику; перезапустить сервис; проверить цепочку с несколькими участниками.
Проверить утечку личной памяти отдельным вопросом в созвоне и в Minecraft.

API звукового транспорта сверено с
[sounddevice Raw Streams](https://python-sounddevice.readthedocs.io/en/latest/api/raw-streams.html),
формат входа — с
[VoiceChatIntegration UnionClef v0.95.61](https://github.com/3ndetz/unionclef/blob/v0.95.61/src/main/java/adris/altoclef/util/agent/VoiceChatIntegration.java).
