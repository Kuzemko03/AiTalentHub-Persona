# Решения текущего этапа

Выбран трек 2: собственная база. Пример рабочего места взят из
[agent-workplace](https://github.com/3ndetz/agent-workplace), commit
`fc5f29344b011af3d79c1d0ea6398e09e84bf57f`. `tools/check.py` и
`tools/compose_session.py` сохранены с MIT-лицензией; личность и правила
написаны под Джокера, вымышленные заметки исходного примера не перенесены.

## Модель

По запросу владельца основной адаптер вызывает установленный Codex CLI.
Сохранённый вход проверен через `codex login status`; проба `gpt-6-luna`
дала настоящий ответ. CLI выдаёт события JSONL и финальный ответ по схеме.
Каждая генерация получает собственную временную папку и не возобновляет
общий CLI-диалог. Память принадлежит приложению.

Использованы [режим non-interactive](https://learn.chatgpt.com/docs/non-interactive-mode),
[документация входа](https://learn.chatgpt.com/docs/auth) и локальная
справка `codex exec --help` версии `0.162.0-alpha.17.2`.
Ключевые опции: `--json`, `--output-schema`, `--ephemeral`,
`--ignore-user-config`, `--sandbox read-only`. Доступность модели и лимиты
определяет текущий аккаунт; смена модели задаётся `CODEX_MODEL`.

Для сохранения границы между личным ботом и coding-agent отключены
командные инструменты, браузер, приложения и плагины. Telegram-токен
не входит в окружение дочернего процесса. Публично публикуется код,
а запущенный экземпляр принимает запросы только от владельца.

## Состояние и маски

Активная маска и факты находятся в разных таблицах SQLite. Данные масок
хранятся в JSON; пользовательские профили — в приватной базе. Память
общая для каналов владельца; в коде поддерживается отдельный actor для
изоляции будущих собеседников. Короткая история ограничена 12 репликами.

Каждый ответ получает ревизию. Смена маски или стоп отменяют запущенный
процесс; устаревший результат не доставляется после изменения состояния.
Telegram хранит входящие задания и рассчитанные ответы отдельно,
отбрасывает повторные update_id и сохраняет offset.

## Интерфейсы

Telegram — [Bot API](https://core.telegram.org/bots/api), long polling:
`getMe`, `getWebhookInfo`, `getUpdates`, `sendMessage`,
`answerCallbackQuery`. Никаких входящих портов для Telegram не нужно.
Панель слушает только loopback, проверяет Host и ключ запросов,
обслуживает фиксированные маршруты и не предоставляет доступ к файлам.

## Объём

Только стандартная библиотека Python 3.11+. PostgreSQL, Redis, Docker,
векторный поиск и тяжёлые speech-модели для этого этапа не требуются.
Настоящее игровое поручение появится после подключения UnionClef.
Это текущий текстовый срез проекта, а не итоговая автономная система.
